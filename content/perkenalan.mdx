Halo! Selamat datang di **NukeTheFoids.fun** — ruang pribadi saya untuk mendokumentasikan catatan teknis, ide, dan pemikiran seputar pengembangan perangkat lunak.

Blog ini dibangun dengan pendekatan minimalis: tanpa database, tanpa CMS berbayar, hanya file dan code. Semua artikel ditulis dalam format MDX sehingga saya bisa mencampur markdown dan JSX langsung di dalam tulisan.

## Kenapa Mulai dari Sini?

Saya percaya bahwa menulis adalah cara terbaik untuk mengonsolidasikan pengetahuan. Setiap kali saya mempelajari sesuatu yang baru, saya mendokumentasikannya di sini. Jika ada yang bermanfaat untuk orang lain, itu adalah bonus.

## Arsitektur Blog Ini

Tech stack yang dipakai sengaja dipilih supaya tetap ringan dan cepat:

- **Next.js** — App Router untuk routing dan rendering
- **Bootstrap** — Styling tanpa perlu custom CSS yang berlebihan
- **Local MDX** — Konten disimpan sebagai file, bukan database
- **Vercel** — Hosting gratis dengan deploy otomatis

![Ilustrasi konsep](/blog/sample-image.jpg)

Filosofi utamanya sederhana: **simpel, cepat, dan fokus pada konten**. Tidak ada elemen dekoratif yang mengganggu — semuanya ada supaya pembaca bisa fokus membaca.

## Yang Bisa Kamu Harapkan

Di blog ini saya akan menulis tentang:

- Teknologi dan pemrograman
- Pengalaman pribadi dalam pengembangan perangkat lunak
- Tips dan trik seputar web development
- Pemikiran kritis tentang tren industri

Terima kasih sudah mampir. Semoga artikel ini bermanfaat!
